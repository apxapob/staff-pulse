# Staff Pulse

Дашборд организационной структуры компании. React, Vite, TypeScript, styled-components и собственный mock API на Node.js.

## Запуск

Node.js 22.12+ и npm. Из корня проекта:

```sh
npm install && npm run dev
```

Приложение: http://localhost:5173. API: http://localhost:3001/api/org-tree.

```sh
npm run check
```

## Этапы

- `step/1` — foundation: API, валидация, кэширование и дерево.
- `step/2` — core: агрегаты, таблица, сортировка и фильтрация.
- `step/3` — polish: live-патчи, восстановление соединения и доступность.
- `step/4` — bonus: Docker, Nginx, естественно-языковой поиск и документация.

## AI в разработке

Приложение разработано с OpenAI Codex: генерация каркаса, доменной модели, mock API, компонентов, тестов и документации. Несколько агентов работали над независимыми частями; интеграция и проверка выполнялись основным агентом. В этом процессе код человеком вручную не переписывался; утверждать обратное было бы неверно. Конкретные исправления после проверок будут описаны по завершении этапов.
